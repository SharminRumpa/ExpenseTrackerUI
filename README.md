# ExpenseTrackerUI

A modern expense management UI built with **Angular** and integrated with **ASP.NET Core Web API**.

## Features

- Dashboard with expense summary
- Add, edit, and delete expenses
- Expense categories
- Search and filtering
- Monthly and category-wise reports
- Responsive design
- REST API integration

## Tech Stack

- Angular
- TypeScript
- HTML5 / CSS3
- Bootstrap
- ASP.NET Core Web API
